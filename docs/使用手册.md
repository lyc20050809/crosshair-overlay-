# Crosshair Overlay 使用手册

版本 1.0.0

## 1. 这是什么

一个独立的 Windows 准星叠加工具。核心设计：**准星按"分辨率"设计，而不是按"像素大小"设计**。
你选一个画布（800×600、1080p、native……），在画布里画准星，工具再把画布映射到显示器。

不写注册表、不装服务、不注入游戏进程，删掉文件夹就是卸载。

## 2. 安装

1. 把 `CrosshairOverlay.exe` 放到任意目录（例如 `C:\Tools\CrosshairOverlay\`）；
2. 双击运行；Windows 可能提示未签名，选「更多信息 → 仍要运行」；
3. 屏幕上出现准星，右下角出现托盘图标。

首次运行会在 exe 旁边生成 `crosshair.ini`；`presets.ini`、`profiles.ini` 在用到时生成。

**环境要求**：Windows 10/11 64 位、.NET Framework 4.x（系统自带）。

## 3. 第一次使用

| 步骤 | 操作 |
|---|---|
| 1 | 按 `F6` 打开设置窗口 |
| 2 | 选画布（默认 `800×600`，想 1:1 就选 `native`） |
| 3 | 调颜色、形状、臂长、线宽、间隙 |
| 4 | 点「保存配置」写入 `crosshair.ini` |
| 5 | `F8` 显示/隐藏，`Ctrl+Alt+Q` 退出 |

窗口里的改动**实时生效**，但只有点「保存配置」才会写盘。

## 4. 画布

准星用**画布像素**描述，渲染时按比例放大：

```
scaleX = 屏幕宽 / 画布宽
scaleY = 屏幕高 / 画布高
```

例：画布 800×600，屏幕 2560×1440（`stretch`）

| 画布尺寸 | 缩放 | 屏幕上 |
|---|---|---|
| 横臂 6px | ×3.2 | 19.2px |
| 竖臂 10px | ×2.4 | 24px |
| 线宽 2px | ×3.2 / ×2.4 | 6.4 × 4.8px |

### 三种 CanvasFit

| 值 | 行为 | 适用 |
|---|---|---|
| `stretch` | 拉满屏幕，X/Y 独立缩放 | 游戏把 4:3 拉伸到 16:9 |
| `fit` | 保持比例、留黑边 | 游戏保持宽高比 |
| `native` | 画布 = 屏幕，1:1 | 想要固定屏幕像素的准星 |

### 为什么先栅格化再放大

渲染器先把准星画进一张「画布大小」的位图，再整张放大。这样准星被量化到画布像素网格，
和游戏以该分辨率渲染的效果一致。放大算法由 `Upscale` 决定：

- `nearest`（默认）：硬块、清晰；
- `bilinear`：更柔，放大倍数大时会发糊。

## 5. 设置窗口（F6）

**画布组**：预设、宽/高、模式、像素对齐、放大方式、锚点 X/Y、逐像素透明。

**准星组**：形状、颜色、横臂/竖臂、线宽 X/Y、间隙 X/Y、描边（可只描两侧）、不透明度、
横竖等长、柔和边缘（旧方案）、光晕。

**底部**：保存配置 / 存为当前游戏 / 准星存档库 / 关闭 / 退出。

## 6. 准星存档库

点「存档库...」打开卡片式界面：

- 每张卡片是**实时缩略图 + 名称 + 画布**，渲染逻辑与叠加层完全相同；
- 左键卡片载入，右键可载入/删除；
- 底部输入名字 → 「保存当前准星为存档」。

存档存在 `presets.ini`，按名字分节，可手改。

## 7. 逐游戏配置

`profiles.ini` 把进程名映射到画布和尺寸：

```
cs2.exe = 800x600|stretch|6,10|2,2|4,4
```

格式：`画布宽x高|模式|横臂,竖臂|线宽X,线宽Y|间隙X,间隙Y`。

程序每 0.8 秒检查前台进程，命中就套用；切到没有配置的程序时回到 `crosshair.ini` 的全局值。
一般不用手写：进游戏调好，点「存为当前游戏」即可。

## 8. 命令行

GUI 版没有控制台，脚本请用 `CrosshairOverlay.CLI.exe`：

| 命令 | 作用 |
|---|---|
| `--version` | 打印版本 |
| `--selftest` | 跑测试，退出码 0 = 通过 |
| `--render out.png [裁剪]` | 把当前准星渲染成 PNG（诊断） |
| `--snapshot shot.png` | 截取准星周围 160×160 屏幕区域 |
| `--geom` | 打印窗口位置与透明模式 |
| `--profiles` | 列出解析后的逐游戏配置 |
| `--presets` | 自检存档库（保存/载入/删除） |

## 9. 编译与测试

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
CrosshairOverlay.CLI.exe --selftest --config crosshair.ini
```

只依赖 Windows 自带的 .NET Framework 编译器，无第三方库。测试覆盖配置读写、profile/preset
解析、像素几何、对称性、抗锯齿。

## 10. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 游戏里看不到 | 独占全屏无法叠加，改「无边框窗口化」 |
| 准星周围一块品红/黑 | `AlphaMode=1` 在部分驱动下不可用，改回 `0` |
| 改完透明模式后准星消失 | 窗口样式在创建时固定，需重启程序 |
| 两个准星 | 同时开了多个实例；现在只允许一个，关掉旧的 |
| 热键无反应 | 被其他软件占用，改 ini 里的热键 |
| 太糊 | `Upscale=0`、把画布调大、降低 `Glow` |
| 光晕太强 | `Glow` 调到 20–30，或设 0 |

## 11. 限制

- 独占全屏游戏无法覆盖，这是 DWM 的限制，任何叠加层都一样；
- 读不到游戏内部渲染分辨率（需要注入进程，本工具不做），所以画布按游戏手动选、按进程记住；
- 逐像素透明依赖桌面合成器，个别驱动会渲染异常，此时用色键透明兜底。

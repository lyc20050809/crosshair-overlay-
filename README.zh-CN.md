# Crosshair Overlay（带自定义画布的准星叠加工具）

一个单文件、无依赖的 Windows 准星叠加工具。核心特点：**准星不是按屏幕像素定义，而是按你自己设定的"画布分辨率"定义，再按比例映射到屏幕。**

## 1. 运行

双击 `CrosshairOverlay.exe`。首次运行若没有 `crosshair.ini`，会自动生成一份默认配置。

- 不会安装任何东西，不写注册表，删掉文件夹就完全卸载。
- 启动后没有窗口，只有右下角托盘图标 + 屏幕上的准星。
- 按 `F6` 打开设置窗口；托盘右键也有菜单。
- 退出：设置窗口"退出程序"、托盘右键 → 退出程序，或 `Ctrl+Alt+Q`。
- 未签名 exe，Windows 可能弹 SmartScreen，点"更多信息 → 仍要运行"。

## 2. 热键

| 键 | 作用 |
|---|---|
| `F6` | 打开 / 前置设置窗口 |
| `F7` | 切换画布预设 |
| `F8` | 显示 / 隐藏准星（出问题先按这个） |
| `F9` | 切换颜色 |
| `F10` | 重新读取 `crosshair.ini` |
| `Ctrl+Alt+Q` | 退出程序 |

## 3. 为什么之前会黑屏盖住设置窗口（已修复）

旧版把准星层做成了**全屏窗口**，靠"逐像素透明"把它变透明。一旦这个透明模式在某个系统/显卡上失效，全屏窗口就退化成一块不透明的大黑块，还是 `TopMost`，于是把设置窗口整个盖住了 —— 表现就是"按 F6 没反应"。

现在改成两层保险：

1. **窗口只有准星那么大**：不再是全屏，而是一个 100 多像素见方的小窗口，正好套在准星位置。就算透明完全失效，受影响的也只是准星周围那一小块，不会挡住任何界面。
2. **默认用色键透明**（`TransparencyKey`），兼容性最好；`AlphaMode=1` 才用逐像素透明。

另外：

- 设置窗口是 `TopMost`，而且**打开设置时叠加层会暂停抢置顶**，不会再被顶下去；
- 设置窗口默认停靠在屏幕左侧，不挡屏幕中央的准星，方便边调边看；
- 热键注册失败（被别的软件占用）会在托盘弹气泡提示。

## 4. 可视化设置窗口（F6）

**画布**
- `预设`：下拉，选中后自动填宽高（`native` = 跟随屏幕）
- `宽` / `高`：画布分辨率
- `模式`：`stretch` 拉伸 / `fit` 等比留边 / `native` 1:1
- `像素对齐`：勾上 = 坐标取整、线条硬朗
- `锚点 X/Y%`：准星在画布里的位置，50/50 是正中
- `逐像素透明`：见第 3 节，改完需重启

**准星**（单位都是画布像素）
- `形状`：cross / dot / circle / x / t
- `颜色`：`选择...` 取色器，或直接输入 `#RRGGBB`
- `横臂` `竖臂` `线宽 X` `线宽 Y` `间隙 X` `间隙 Y` `描边` `不透明度`
- `只描两侧`：描边只加在长边的两侧，不加端帽、不填中心间隙（细准星必须开，否则 1px 描边会把 1px 的线撑成 3px 的方块）
- `柔和边缘（抖动）`：旧方案，仅色键透明时有用；开了逐像素透明就关掉
- `光晕`（0–100）：在准星周围加一圈同色柔光，**只在逐像素透明下生效**。
  - 0 = 只有抗锯齿的硬边（最锐）
  - 20–40 = 一点点“发虚”（推荐起点）
  - 60 以上 = 明显光晕，接近辉光效果
- `放大`（画布区）：`最近邻` / `双线性`
  - **最近邻**：边缘清晰、有台阶感（默认，推荐）
  - **双线性**：边缘更糊、更"糯"，除非你要那种柔焦感，否则会显得糊

**准星太糊怎么办**：模糊来自三处叠加 —— ①画布比屏幕小（比如 800×600 放大到 2560×1440，本身就会放大）；②`放大=双线性`；③`光晕` 太高。把 `放大` 设成 `最近邻`、`光晕` 降到 20–30，并把画布调大（或按 F7 切到 native），就能找到清晰与柔和的中间值。

**描边为什么会"显得很大"**：描边是**绝对像素**，不按比例。`描边=1` 在四条边上各加 1px ——
- 1px 粗的臂 → 3px 粗（左右各 1）
- 2px 长的臂 → 4px 长（两端各 1）
- `间隙=0` 时四条臂的描边在中心重叠 → 变成一个实心黑方块

所以细准星要么 `描边=0`，要么勾 `只描两侧`（新版默认），要么把线宽调到 2 以上再描边。

**底部**
- `应用并保存 (Enter)` 写回 ini
- `关闭窗口 (Esc)` 只关窗，准星继续
- `退出程序` 彻底退出

窗口里任何改动都**实时生效**。

### 横竖等长（左右对称）

勾上 `横竖等长（长度 / 线宽 / 间隙 同步）` 后：

- 竖臂长度自动跟随横臂、线宽 Y 跟随线宽 X、间隙 Y 跟随间隙 X，Y 那三个输入框变灰；
- 想单独调横竖比例（比如做扁准星）就取消勾选。

另外，绘制逻辑从这一版起改成 **以中心点为唯一基准** 计算：

```
取整中心点 → 取整 gap / 长度 / 线宽 → 左右臂用同一组整数
左臂：x = cx - gap - len，宽 len
右臂：x = cx + gap，      宽 len
```

左右两条臂用的是**同一组整数**，所以不会再出现“左边长一像素、右边短一像素”这种由分别四舍五入造成的偏差。

### 准星存档（presets.ini，自定义名字）

设置窗口底部有「准星存档」：

- `名称`：给当前准星起个名字（比如“2K 细十字”）；
- `保存`：把当前画布 + 尺寸 + 颜色 + 形状 + 描边 + 透明度整个存进 `presets.ini`；
- `存档库...`：打开**可视化存档库**（见下）；
- `已存` 下拉选存档 → `载入` 立刻套用；
- `删除` 移除该存档。

#### 可视化存档库

点「存档库...」（或托盘右键 → 准星存档库），像游戏读档界面一样：

- 每个存档一张卡片：**准星缩略图 + 名字 + 画布信息**；
- **左键卡片** → 立刻载入；
- **右键卡片** → 载入 / 删除；
- 底部输入名字 → 「保存当前准星为存档」。

缩略图是用真实渲染逻辑画的（`CrosshairDraw` 和叠加层共用同一套代码），所以预览和实际显示一致。

文件是按名字分段的 INI，也可以手改：

```ini
[2K 细十字]
Canvas=2560x1440
Fit=stretch
Anchor=50,50
Size=6,10
Thickness=2,2
Gap=4,4
Color=#00FF00
Shape=cross
Outline=1
OutlineMode=1
SyncArms=1
Alpha=255
```

和 `profiles.ini` 的区别：**profiles 是按游戏自动切**（一次性绑定），**presets 是手动存档库**（随时载入任意一套）。

### 逐游戏配置（profiles.ini）

每个游戏可以有自己的画布和准星尺寸，程序每 0.8 秒检查一次前台窗口：

```
cs2.exe = 800x600|stretch|6,10|2,2|4,4
```

格式：`进程名 = 画布宽x画布高|模式|横臂,竖臂|线宽X,线宽Y|间隙X,间隙Y`

- 切到匹配的游戏 → 自动套用；
- 切到没配置的程序 → 回到 `crosshair.ini` 的全局默认；
- 生成方法：进游戏 → `F6` 调好 → 点「存为当前游戏」。

命令行自检：`CrosshairOverlay.exe --profiles --config crosshair.ini` 会逐条打印解析结果。

### 真正按画布分辨率渲染

准星不是在屏幕坐标里"按比例算"出来的，而是：

1. 新建一张 `画布宽 × 画布高` 的位图（1 单位 = 1 画布像素）；
2. 在这张位图上用整数坐标画准星；
3. 把整张位图用 **最近邻（NearestNeighbor）** 放大到显示器。

所以 800×600 画布下 1px 的线，放大 3.2×2.4 之后就是 **3.2×2.4 的方块**，边缘带台阶 —— 和游戏用 800×600 渲染再拉伸到 2K 的观感一致。关掉 `像素对齐` 则改用抗锯齿 + 双线性放大。

调试命令（输出 PNG，可直接看效果）：

```
CrosshairOverlay.exe --render out.png --config crosshair.ini 240
```

最后一个数字是裁剪边长（默认 240px，以屏幕中心裁）。

## 5. "画布"到底是什么

```
scaleX = 屏幕宽 / 画布宽
scaleY = 屏幕高 / 画布高
屏幕上的长度 = 画布长度 × scaleX（横向）/ scaleY（纵向）
```

例子：2K 屏 2560×1440，画布 800×600，`CanvasFit=stretch`

| | 画布 | 缩放 | 屏幕 |
|---|---|---|---|
| 横臂 6px | 6 × 3.2 | scaleX=3.2 | 19.2px |
| 竖臂 10px | 10 × 2.4 | scaleY=2.4 | 24px |

切成 `2560x1440` 或 `native` 就是 1:1 屏幕空间效果。

- `stretch`：拉满屏幕，X/Y 缩放不同（模拟 4:3 拉伸到 16:9）
- `fit`：等比放大、两侧留黑边
- `native`：画布 = 屏幕

## 6. 配置文件

| 键 | 说明 |
|---|---|
| `Colors` | 颜色列表，`#RRGGBB`，F9 循环 |
| `Shape` | `cross` / `dot` / `circle` / `x` / `t` |
| `Outline` `OutlineColor` | 描边宽度 / 颜色 |
| `Alpha` | 不透明度 0–255 |
| `Screen` | 画在第几个屏幕（0 = 主屏） |
| `PixelSnap` | 1 = 取整硬朗；0 = 抗锯齿 |
| `AlphaMode` | 0 = 色键透明（默认）；1 = 逐像素透明（需重启） |
| `CanvasWidth` `CanvasHeight` | 画布分辨率 |
| `CanvasFit` | `stretch` / `fit` / `native` |
| `CanvasPresets` | F7 循环的预设 |
| `AnchorX` `AnchorY` | 准星在画布内的位置（%） |
| `SizeX` `SizeY` | 横臂 / 竖臂（画布像素） |
| `ThicknessX` `ThicknessY` | 竖线宽 / 横线高（画布像素） |
| `GapX` `GapY` | 中心留空（画布像素） |
| `KeySettings` `KeyToggle` `KeyColor` `KeyCanvas` `KeyReload` `KeyExit` | 热键 |

## 7. 排查

| 现象 | 处理 |
|---|---|
| 按 F6 没反应 | 看右下角托盘图标，右键 → 设置；或双击托盘图标 |
| 屏幕上有黑块 | 按 `F8` 先隐藏；然后确认 `AlphaMode=0`，重启程序 |
| 准星位置不对 | 检查 `Screen`（第几个屏幕）与 `AnchorX/Y` |
| 游戏里看不到 | 游戏必须用**无边框窗口化**，独占全屏盖不上去 |
| 热键失效 | 被其他软件占用，改 `crosshair.ini` 里的热键后按 F10 |

## 8. 已知限制

1. **独占全屏（Exclusive Fullscreen）画不上去** —— DWM 合成顺序决定，跟画布无关。
2. **无法自动读取游戏内部分辨率** —— 需要注入/hook，那是外挂手法，不做。按游戏实际渲染分辨率手动选画布：
   - 1080p 原生 → `1920x1080` 或 `native`
   - 720p 渲染 + FSR 超分到 2K → `1280x720`
   - 800×600 拉伸 → `800x600` + `stretch`
3. **不要在联网竞技游戏里用**（尤其带 ACE/EAC 反作弊的）。纯 GDI 叠加层技术上不是注入，但部分反作弊会把覆盖层判为可疑，有封号风险。
